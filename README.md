# australia-cv-maker

**Australian Résumé Studio (v1) · 澳洲打工度假履歷產生器**

A standalone, privacy-first, offline-ready web application designed for working holiday makers and job seekers in Australia to generate targeted, professional 1-page A4 résumés.
專為澳洲打工度假青年、留學生及求職者設計的隱私安全、可離線使用之網頁工具，協助快速產生符合澳洲就業標準的一頁式 A4 專業履歷。

## ✨ Features / 核心功能

1. **8 Visual Style Palettes / 8 種道地澳洲視覺風格**
   - **Modern Café / 現代咖啡館** (Warm cream, espresso brown, sage green)
   - **Clean Professional / 經典專業** (Crisp white, corporate navy, cool grey)
   - **Boutique Hotel / 精品旅宿** (Ivory, forest green, subtle gold line)
   - **Fresh Minimal / 清新極簡** (Bright white, charcoal, mint accents)
   - **Warm Hospitality / 溫暖餐旅** (Warm beige, brick red, dark cocoa)
   - **Contemporary Australian / 當代澳洲** (Sandstone, eucalyptus green, charcoal)
   - **ATS Classic / ATS 經典** (High contrast monochrome, machine-reading optimized)
   - **Compact One-page / 精簡一頁式** (Space-saving typography for experienced applicants)

2. **12 Pre-configured Target Roles / 12 種熱門求職職位模板**
   - Café All-rounder (咖啡館全能人員)
   - Barista Assistant (咖啡師助理)
   - Kitchen Hand (廚房助手)
   - Food & Beverage Attendant (餐飲外場服務)
   - Wait Staff (外場服務生)
   - Restaurant All-rounder (餐廳全能服務)
   - Hotel Housekeeper (飯店客房清潔)
   - Room Attendant (客房服務員)
   - Commercial Cleaner (商業清潔人員)
   - Hotel All-rounder (旅宿全能人員)
   - Storeperson / Warehouse (倉儲理貨人員)
   - General Labourer (一般勞務工人)

3. **Complete Personal Customization / 支援任何人自訂個人內容**
   - Custom English name, email, Australian phone, location, availability dates, and roster flexibility.
   - Clear Visa and work rights statement (Subclass 417 / 462).
   - Editable professional summary, transferable skills, multi-job work history, and education.
   - Dynamic licences and tickets checklist (Driver Licence, IDP, RSA WA, Food Handler, White Card, First Aid).

4. **Live A4 Preview & 1-Click PDF Export / 即時 A4 預覽與完美單頁列印**
   - Instant visual update upon typing.
   - Zoom controls: In, Out, and FIT to screen width.
   - Configured with strict `@media print` rules for browser Print → Save as PDF without margin bugs or header/footer noise.
   - Quick "Copy for Seek / Indeed" button to get formatted plain text.

5. **Privacy & Offline First / 隱私優先與離線安全**
   - 100% client-side computation. No data is sent to any remote server.
   - Automatic `localStorage` persistence saves your work continuously.
   - JSON export and import capabilities to backup and restore profiles.
